# Отчёт: Анализ предметной области «Автосалон»

## Описание предметной области
Автосалон занимается продажей автомобилей различных марок. Клиенты приходят в салон, выбирают автомобиль, и сотрудник оформляет продажу.

## Выделенные сущности
1. **Марка** — производитель автомобиля (Toyota, BMW, Lada и т.д.)
2. **Автомобиль** — конкретная модель с характеристиками
3. **Клиент** — покупатель автомобиля
4. **Сотрудник** — менеджер, оформляющий продажу
5. **Продажа** — факт совершения сделки

## Бизнес-правила
- У каждой марки может быть много моделей автомобилей
- Один автомобиль продаётся один раз (одна продажа)
- Один клиент может совершить несколько покупок
- Один сотрудник может оформить несколько продаж
- Каждая продажа связана с одним клиентом, одним автомобилем и одним сотрудником
